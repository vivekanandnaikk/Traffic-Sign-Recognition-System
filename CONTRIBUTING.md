# Contributing

Issues and pull requests are welcome. Please keep contributions focused, documented, and reproducible.

## Before contributing

- Check whether the project scope and implementation status are documented in the README and `docs/`.
- Confirm that datasets, pretrained weights, and other assets may be used and shared under their applicable terms.
- Do not commit private or restricted data, large datasets, model weights, or generated results unless explicitly intended and properly licensed.

## Pull requests

- Explain the problem and the proposed change.
- Include relevant validation steps and results; do not imply tests or experiments were run if they were not.
- Update documentation when changing project scope, data handling, methods, or reported results.
- Support performance claims with the dataset split, metric, and evaluation procedure.

## Reports and results

Clearly distinguish implemented and verified behavior from planned work. Attribute external datasets, code, and models, and document relevant license or usage terms.
